# MoCap Studio — проверочная Android / HTML5 версия 0.2

Исправление для ошибки «Permission denied» при запуске HTML из Android Downloads: приложение работает в **Capacitor WebView на защищённом https://localhost**, содержит разрешение CAMERA в AndroidManifest и запрашивает разрешение пользователя. Не открывайте файл HTML через Android «Загрузки» для проверки камеры — `content://` не даёт необходимого secure origin.

## Android APK

В GitHub Actions найдите **MoCap Studio Android APK** → **Artifacts → MoCap-Studio-Android-APK** → `app-debug.apk`. Установите APK, откройте, нажмите «Камера» → «Включить камеру» и дайте Android разрешение. В этой сборке Three.js, JS-модули, MediaPipe WASM и Pose Landmarker Lite **встроены в APK**; интернет для обработки камеры не требуется. Видео/кадры не отправляются на сервер.

**Обратите внимание:** это тестовый debug APK. Нужна проверка на реальном Android: различия Android System WebView/GPU/запросов разрешения могут влиять на работу. Устройство должно поддерживать WebGL и WebAssembly.

## HTML5 в браузере

Установить Node.js 22 и исполнить:

```sh
npm install
bash scripts/get-model.sh
npm run dev
```

Локальный адрес `http://localhost:5173` разрешён для камеры на компьютере. На Android браузеру нужен **HTTPS-сайт** с опубликованным содержимым `dist`, которое можно получить `npm run build` и загрузить на Cloudflare Pages. **Не открывать `index.html` через файловый менеджер**.

## Экспорт

**GLB** с Mixamo-подобным скелетом тестового манекена и ключами верхней части тела либо **JSON** с временными метками. В Android используется системное окно **«Поделиться»** через Capacitor Share: выберите приложение для сохранения в файлы. В браузере скачивается файл. Перенос на собственных персонажей нуждается в дальнейшей проверке и ретаргетинге. Ноги и таз не анимируются.

При ошибке камеры сначала проверьте **Настройки Android → Приложения → MoCap Studio → Разрешения → Камера**. Ошибки геометрии/экспорта не являются следствием запрета камеры.
