# MoCap Studio — Android / HTML5

Проект захвата движений верхней части тела человека с камеры или видео для создания скелетной анимации GLB/JSON.

В версии 0.2 — MediaPipe Pose, Three.js, сборка Capacitor APK с разрешением камеры и локальной моделью. Предыдущий запуск HTML напрямую из `content://` на Android блокировал доступ к камере; в APK используется защищённое происхождение `https://localhost`.

Сборка будет доступна в **Actions → MoCap Studio Android APK → Artifacts → MoCap-Studio-Android-APK**.

Внимание: это тестовый прототип; реальную работу камеры и качество переноса движений необходимо проверить на Android-устройстве.
